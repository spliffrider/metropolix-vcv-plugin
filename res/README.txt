UI assets

Roboto-Bold.ttf: Google's Roboto 2 static hinted Bold font.
Source: https://github.com/googlefonts/roboto-2/blob/main/src/hinted/Roboto-Bold.ttf
Upstream license is included as Roboto-LICENSE.txt.

intellijel-manual-logo.png: the unmodified embedded logo image from the
user-supplied Metropolix 1.6 manual (2025-09-24), page 28 PDF image X18.
intellijel.svg: a vector trace of that image, generated reproducibly by
scripts/trace-reference-logo.py. Used to follow the requested hardware artwork.
The Intellijel name and artwork identify the original hardware; this project
is an independent local implementation, not an official Intellijel product.

All other panel components and the 128x64 display are drawn in C++.
